# PROMPT PARA MIGRACIÓN A ANGULAR 20 - Transporte Colectivo Inteligente Juliaca

## 📋 CONTEXTO DEL PROYECTO

Necesito migrar completamente una aplicación de **Transporte Colectivo Inteligente para Juliaca, Perú** de React a **Angular 20**. La aplicación está dirigida a pasajeros de microbuses con diseño mobile-first y versión web responsiva.

### Objetivos de la aplicación:
- Registro de usuarios con DNI peruano (8 dígitos)
- Creación de tarjetas virtuales con QR único
- Recarga de saldo mediante múltiples métodos
- **Pago de pasajes mediante escaneo del QR del microbus** ⭐ IMPORTANTE
- Consulta de movimientos/historial
- Vista de mapa con ubicación en tiempo real (OpenLayers)
- **Portal para conductores** con tracking GPS (Mapbox + OSRM)

## 🔄 FLUJO DE PAGO CORREGIDO ⭐⭐ MUY IMPORTANTE

### ❌ NO IMPLEMENTAR (Flujo antiguo):
~~Pasajero selecciona adultos/escolares → Genera su propio QR → Muestra al validador~~

### ✅ IMPLEMENTAR (Flujo correcto):

```
1. Pasajero presiona "Escanear QR" en MyCard
   ↓
2. Se abre ScanQRComponent con cámara activa
   ↓
3. Pasajero escanea el QR FIJO del microbus
   (QR impreso en la entrada del vehículo)
   QR contiene: "BUS:ABC123:Ruta 5:VALID001"
   ↓
4. Sistema extrae datos:
   - placa: "ABC123"
   - ruta: "Ruta 5"  
   - validador: "VALID001"
   ↓
5. Navega automáticamente a PayFareComponent
   Con datos del bus en queryParams
   ↓
6. Pasajero selecciona adultos/escolares
   ↓
7. Presiona "Pagar S/ X.XX"
   → Pago instantáneo, NO genera QR
   → Descuenta saldo inmediatamente
   ↓
8. Muestra Ticket de confirmación
```

**Clave**: El pasajero **NO genera QR**, sino que **escanea el QR del microbus**.

**Componente Angular**:
```typescript
@Component({
  selector: 'app-scan-qr',
  templateUrl: './scan-qr.component.html'
})
export class ScanQRComponent {
  isScanning = false;
  
  constructor(
    private router: Router,
    private busService: BusService,
    private toastr: ToastrService
  ) {}
  
  onScanSuccess(qrData: string) {
    try {
      const busData = this.busService.parseBusQR(qrData);
      this.toastr.success('¡QR escaneado exitosamente!');
      
      this.router.navigate(['/pay-fare'], {
        queryParams: busData
      });
    } catch (error) {
      this.toastr.error('QR inválido. Intenta de nuevo.');
    }
  }
  
  // Solo para demo
  simulateScan() {
    this.isScanning = true;
    
    setTimeout(() => {
      this.onScanSuccess('BUS:ABC123:Ruta 5:VALID001');
    }, 1500);
  }
}
```

**Servicio BusService**:
```typescript
@Injectable({ providedIn: 'root' })
export class BusService {
  parseBusQR(qrData: string): BusData {
    // Formato: BUS:ABC123:Ruta 5:VALID001
    const parts = qrData.split(':');
    
    if (parts[0] !== 'BUS' || parts.length < 4) {
      throw new Error('Formato de QR inválido');
    }
    
    return {
      placa: parts[1],
      ruta: parts[2],
      validador: parts[3]
    };
  }
}
```

```typescript
@Injectable({ providedIn: 'root' })
export class BusService {
  /**
   * Parsea el QR del microbus
   * Formato esperado: "BUS:{placa}:{ruta}:{validador}"
   * Ejemplo: "BUS:ABC123:Ruta 5:VALID001"
   */
  parseBusQR(qrData: string): BusData {
    const parts = qrData.split(':');
    
    if (parts[0] !== 'BUS' || parts.length < 4) {
      throw new Error('Formato de QR inválido');
    }
    
    return {
      placa: parts[1],
      ruta: parts[2],
      validador: parts[3]
    };
  }
  
  /**
   * Valida si un QR es de tipo BUS
   */
  isValidBusQR(qrData: string): boolean {
    try {
      this.parseBusQR(qrData);
      return true;
    } catch {
      return false;
    }
  }
  
  /**
   * Genera un QR de bus (para admin/conductor)
   * En producción esto vendría del backend
   */
  generateBusQR(placa: string, ruta: string, validador: string): string {
    return `BUS:${placa}:${ruta}:${validador}`;
  }
}
```

## ✅ VALIDACIONES Y LÓGICA DE NEGOCIO

### Validaciones de formularios:

**DNI**:
- Exactamente 8 dígitos numéricos
- Regex: `/^\d{8}$/`

**Email**:
- Formato estándar
- Regex: `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`

**Celular**:
- 9 dígitos numéricos
- Comienza con 9
- Regex: `/^9\d{8}$/`

**Placa (conductores)**:
- 6-7 caracteres alfanuméricos
- Uppercase automático
- Regex: `/^[A-Z0-9]{6,7}$/`

**Contraseña**:
- Mínimo 6 caracteres
- Sin restricciones adicionales en v1

**Edad (registro)**:
- Mínimo 12 años
- Calcular desde `fechaNacimiento`

**QR de microbus** ⭐:
- Formato: `BUS:{placa}:{ruta}:{validador}`
- Ejemplo válido: `BUS:ABC123:Ruta 5:VALID001`
- Partes: 4 exactamente, separadas por `:`
- Primera parte debe ser "BUS"

### Lógica de saldo:

## 🎯 FLUJOS CLAVE CORREGIDOS

### ✅ CORRECTO - Flujo de pago de pasaje:

```
1. Pasajero en MyCard → Click "Escanear QR"
   ↓
2. Se abre ScanQRComponent
   ↓
3. Pasajero apunta cámara al QR del microbus (en la entrada)
   QR contiene: "BUS:ABC123:Ruta 5:VALID001"
   ↓
4. Sistema detecta y parsea QR:
   - placa: "ABC123"
   - ruta: "Ruta 5"
   - validador: "VALID001"
   ↓
5. Toast: "¡QR escaneado exitosamente!"
   ↓
6. Navega automáticamente a PayFareComponent
   Con queryParams: ?placa=ABC123&ruta=Ruta%205&validador=VALID001
   ↓
7. PayFare muestra:
   - Card azul con info del bus (placa, ruta, validador)
   - Selección de adultos (1 por defecto)
   - Selección de escolares (0 por defecto)
   - Total calculado dinámicamente
   ↓
8. Pasajero ajusta cantidades
   ↓
9. Click "Pagar S/ {total}"
   - Valida saldo suficiente
   - Descuenta saldo inmediatamente
   - NO genera QR, pago directo
   ↓
10. Toast: "¡Pago exitoso! Puedes abordar el microbus"
    ↓
11. Navega a TicketComponent con confirmación
    ↓
12. Backend (simulado):
    - Registra transacción en pasajero
    - Incrementa contador en DriverMap automáticamente:
      * passengerCount += adultos + escolares
      * totalCollected += total
```

### ❌ INCORRECTO - No implementar:

```
❌ Pasajero genera su propio QR
❌ Validador escanea QR del pasajero
❌ Conductor añade pasajeros manualmente con botones +/-
```

### ✅ Integración con Conductor (Backend en v2):

```
Cuando pasajero paga:
1. Se registra transacción en TransactionService
2. Se envía evento a backend (en v2):
   {
     busPlaca: "ABC123",
     ruta: "Ruta 5",
     adultos: 1,
     escolares: 0,
     total: 1.00,
     timestamp: Date.now()
   }
3. Backend notifica al DriverMap via WebSocket (en v2)
4. DriverMap actualiza automáticamente:
   - passengerCount++
   - totalCollected += 1.00
5. Conductor ve actualización en tiempo real
```

**En v1 (demo)**: Usar botón "Simular escaneo QR" en DriverMap para testing

### Preguntas frecuentes:

**Q: ¿Por qué el pasajero ya no genera QR?**
A: Es más rápido y práctico que el pasajero escanee un QR fijo del microbus al subir, en lugar de generar uno nuevo cada vez. El QR está impreso en la entrada del vehículo.

**Q: ¿Cómo se sincronizan los pasajeros con el conductor?**
A: En v1 es simulado. En v2 (producción) se usará WebSocket para notificar al conductor en tiempo real cuando un pasajero pague.

**Q: ¿Qué pasa si el QR del microbus no funciona?**
A: El sistema mostrará un error y permitirá al pasajero reintentar el escaneo. En producción habrá QR de respaldo.

**Q: ¿El conductor puede agregar pasajeros manualmente?**
A: No. El conductor solo ve estadísticas actualizadas automáticamente cuando los pasajeros pagan al validador.
