## 🔍 VALIDACIONES

### Formularios
- [ ] DNI: Exactamente 8 dígitos numéricos
- [ ] Email: Formato válido
- [ ] Celular: 9 dígitos, comienza con 9
- [ ] Placa: 6-7 caracteres alfanuméricos uppercase
- [ ] Contraseña: Mínimo 6 caracteres
- [ ] Edad: Mínimo 12 años
- [ ] QR de bus: Formato "BUS:placa:ruta:validador"

### Lógica de Negocio
- [ ] Saldo no puede ser negativo
- [ ] No pagar si saldo insuficiente
- [ ] Tarifa adulto: S/ 1.00
- [ ] Tarifa escolar: S/ 0.50
- [ ] Tracking GPS solo cuando "En servicio"
- [ ] Panel expandido automáticamente con nuevo pasajero

## 🚀 DEPLOYMENT

### Opción 1: Vercel (Recomendado)

```bash
# Instalar Vercel CLI
npm i -g vercel

# Deploy
vercel

# Configuración (vercel.json)
{
  "buildCommand": "ng build --configuration production",
  "outputDirectory": "dist/transporte-juliaca/browser",
  "framework": "angular"
}
```

### Opción 2: Netlify

```bash
# Instalar Netlify CLI
npm i -g netlify-cli

# Build
ng build --configuration production

# Deploy
netlify deploy --prod --dir=dist/transporte-juliaca/browser
```

### Opción 3: Firebase Hosting

```bash
# Instalar Firebase CLI
npm i -g firebase-tools

# Login
firebase login

# Init
firebase init hosting

# Deploy
firebase deploy --only hosting
```
